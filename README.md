# selfmemo — セルフモニタリングアプリ

心理状態・エネルギー・思考の状態を毎日1〜2分で記録し、自分の「集中できる状態」と「不調のパターン」を見つけるためのセルフモニタリングアプリです。日記ではなく、心理学・行動科学に基づいた自己観察を目的としています。

## 使い方

ビルド不要の静的Webアプリです。

- `index.html` をブラウザで開くだけで動作します
- またはローカルサーバーで配信します：

```sh
python3 -m http.server 8000
# → http://localhost:8000
```

スマートフォンでは「ホーム画面に追加」するとアプリのように使えます。

## 機能

### 記録（1〜2分で完了）
- **睡眠**：就寝・起床時刻（睡眠時間は自動計算、日またぎ対応）、睡眠の質（0〜10）
- **エネルギー**：朝・昼・夜（0〜10、スライダー）
- **頭の状態**：頭の静かさ／アイデア量／感情の揺れ／不安／身体のだるさ（各0〜10）
- **今日の集中状態**：一つのことを進められた／色々始めた／何も始められなかった／その他
- **今日の脳タイプ**：霧（グレー）／静（緑）／散（黄）／嵐（赤）
- **テキスト**：今日やったこと／思いついたこと（アイデアの避難場所）／メモ

### カレンダー
日付ごとに脳タイプを色分け表示（霧=グレー、静=緑、散=黄、嵐=赤）。タップでその日の記録へ移動。月ごとの脳タイプ集計つき。

### グラフ
エネルギー・頭の静かさ・アイデア量・不安・感情の揺れ・身体のだるさ・睡眠時間・睡眠の質を時系列で表示。複数の指標を重ねて表示でき、期間は7日／30日／90日／全期間から選択。タップ・ホバーで各日の値をツールチップ表示。表形式でも確認できます。

### 分析
- **集中できた日の特徴**：「一つのことを進められた」日とそれ以外の日の平均値を比較
- **脳タイプ別集計**：霧・静・散・嵐それぞれの日の平均値を比較
- **相関分析**：Pearson／Spearman を選択可能。任意の2指標の組み合わせ＋主要ペアの一覧
- **曜日分析**：曜日ごとの集中・エネルギー・不安を比較

※ 集中状態は順序尺度（0=何も始められなかった／1=色々始めた／2=一つのことを進められた）として扱います。表示される相関は関連の強さを示すもので、**因果関係を意味しません**。

### メモ検索
今日やったこと・思いついたこと・メモを対象にした全文検索と、`#タグ` によるタグ検索。

### 設定
- テーマ（自動／ライト／ダーク）
- CSVエクスポート／JSONエクスポート／JSONインポート
- デモデータ投入（動作確認用・過去60日分）
- 全記録の削除

## 設計方針

- **オフラインファースト**：外部ライブラリ・CDN・ネットワーク接続に一切依存しません
- **ローカル保存**：データはブラウザの `localStorage` にのみ保存されます（キー：`selfmemo.records.v1`）
- **入力の速さ最優先**：スライダーとタップ中心、今日の入力をホーム画面の最上位に配置
- **統計の妥当性**：Pearson は積率相関、Spearman は同順位を平均順位で処理した順位相関。ペアで3日以上のデータがない場合は計算しません

## データ形式

1日1レコード。JSONエクスポートの例：

```json
{
  "date": "2026-07-17",
  "bedTime": "23:30",
  "wakeTime": "07:00",
  "sleepQuality": 7,
  "energyMorning": 6, "energyNoon": 7, "energyEvening": 5,
  "mindNoise": 3, "ideaFlow": 6, "moodSwing": 2, "anxiety": 2, "fatigue": 3,
  "focus": "single",
  "brainType": "calm",
  "didToday": "・作業を1件進めた",
  "ideas": null,
  "memo": null,
  "updatedAt": "2026-07-17T21:00:00.000Z"
}
```

CSVエクスポートには計算列 `sleepHours`（睡眠時間）と `energyAvg`（エネルギー平均）も含まれます。

## 注意

- データは端末内にのみ保存されます。機種変更やブラウザデータの削除前に必ずエクスポートしてください
- このアプリは自己観察のためのツールであり、医学的な診断・治療を目的としたものではありません
